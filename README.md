# 📚 Estante Virtual - Frontend

Interface web moderna e aconchegante para gerenciamento de leituras pessoais.

## 🎯 Objetivo
Permitir que o usuário pesquise livros em uma biblioteca pública global, adicione títulos à sua estante pessoal, gerencie o status de leitura e escreva resenhas.

## 🌐 API Pública Consumida
- **Google Books API**: Utilizada para buscar títulos, autores, números de páginas e capas de livros em tempo real.

## 🚀 Como Executar
1. Clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Edge, Firefox).
3. Utilize a barra de pesquisa no topo para buscar livros na API do Google.
